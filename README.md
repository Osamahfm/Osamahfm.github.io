# Osama Hamada Portfolio

A static portfolio website built from Osama Hamada's CV and public GitHub projects.

## Files

- `index.html` - page structure and content
- `styles.css` - responsive visual design
- `script.js` - navigation, project filtering, and icon setup
- `assets/` - profile image, project previews, and downloadable CV

Open `index.html` directly in a browser to preview the site.
